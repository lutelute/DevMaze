## 鉄則・地雷

- **実機検証の前に `document.visibilityState` を見る。** Electron のウィンドウが背面に回ると
  rAF が止まり、d3 のトランジションが1フレームも進まない。ズームも全体表示も「壊れた」ように
  見えるがコードは正常。スクリーンショット（CDP captureScreenshot）も固まる。
  復帰は `osascript -e 'tell application id "com.github.Electron" to activate'`。
  `Page.bringToFront` は Electron には効かない。
- **倍率を測るときは毎回リセットする。** リモート新着バナー(36px)が5分ごとに再表示され、
  詳細パネル(280px)の開閉でも変わる。`location.reload()` → バナー✕ → 測定 の順。
  怠って 59/69/71/73/74% とバラバラの数字を出し、比較にならなかった。
- **zsh は `$VAR` を単語分割しない。** 30個のハッシュを渡したつもりが1引数になり、
  「全件失敗」に見えた。`${=VAR}` が要る。
- **JSX の `return (` 直後に `{/* コメント */}` は置けない。** 500 を返して画面が真っ白になる。
  通常のコメントを関数の外に置く。
- **`useCallback` で定義した関数を、定義より前の `useEffect` の依存配列に入れると TDZ で落ちる。**
  画面が真っ白になり、原因が分かりにくい（キーバインドの登録で踏んだ）。
- **色・形・ラベルは `shared/theme.ts` が唯一の出どころ。** `satisfies Record<CommitType, TypeStyle>`
  にしてあるので、種別が増えたらコンパイルで落ちる。5箇所に写して merge の色を
  食い違わせた前科がある。
- `AnalysisResult` の中身が変わったら `electron/ipc/cache.ts` の `CACHE_VERSION` を上げる（現在4）。
- iCloud 配下ではビルドが必ず落ちる。`npx electron-builder --mac --dir -c.directories.output=/tmp/devmaze-release`。
  **作ってから差し替える**（`test -x "$NEW/Contents/MacOS/DevMaze"` を確認してから rm）。
- `gh release create` は draft + `untagged-...` の URL を先に返す。97MB のアップロード完了を
  待ってから `gh release view` で確認すること。

## 沼ったところ

- **numstat の欠損対応**: `git log --all --numstat` は最初に見つからないオブジェクトで止まる。
  部分クローンで blob が1つ欠けるだけで残り911件の差分を道連れにし、取得率0%になっていた。
  README が謳っていた「部分出力の救出」は**この失敗モードで一度も効いていなかった** ——
  simple-git は `stdOut` を持たず `task` だけを載せてくる（例外の中身を実測して確認）。
  分割取得（200件→半分→1件）に変えて 0%→100%。`tests/salvage.test.ts` に固定済み。
- **行パッキングを左右対称で実装して効果ゼロ**。まとまり表示では compactLanes が全非0レーンを
  ±1 に畳むので、どの行も span=1 になり高さが1pxも減らない。実測で「空きは全部上側」と
  分かって上下別々（ups/downs）に作り直して初めて 178→138px になった。
- **ノードの縦の使用量を中心間距離で測って「半分が空」と誤診した。** まとまりは半径最大30pxある。
  インクの範囲は半径込みで測る。ユーザーに訂正した。
- **沼の帯を箱で囲ったら、30件が重なって赤い壁になり道が消えた。** 縁取りをやめて地面にし、
  さらに「選んだ1件だけ強く出す」に変更（`activeStruggleId`）。
- **沼の輪に深刻度を目一杯振ったら、66件すべてが最大の太さになって画面が赤く沈んだ。**
  荒れたリポジトリは深刻度100が大半。上限は控えめに取る。
- **「1件でも沼を含む」でまとまりに印を付けると 102中85 に付いてミニマップが真っ赤。**
  過半のときだけにして66。それでも多いので、本命は帯の方。
- **fable の統合案「6行で約500px空→80%台」は実測では +3pt（71→74%）だった。**
  行の高さは減ったが、空いたぶんを折り返し最適化が「行を1本増やす」方に使ったため。
  **理論上限は面積比の平方根で約84%**（キャンバス98万px² / 中身138万px²）。
  実装の不出来と手法の限界を分けるために、上限を先に出すこと。
